# 🛍️ PureCart

A full-stack MERN E-Commerce website with user authentication, admin dashboard, Stripe payment integration, and Cloudinary image uploads.

## 🚀 Live Demo

- **Frontend:** https://pure-cart-phi.vercel.app
- **Admin:** https://pure-cart-6vgb.vercel.app

## ✨ Features

- User Authentication (JWT)
- Product Listing & Search
- Shopping Cart
- Stripe Payment
- Cash on Delivery
- Order Management
- Admin Dashboard
- Cloudinary Image Upload

## 🛠️ Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Tailwind CSS
- Stripe
- Cloudinary

## ⚙️ Installation

```bash
git clone https://github.com/EvilDante43/PureCart.git
```

Install dependencies in each folder:

```bash
cd backend && npm install
cd frontend && npm install
cd admin && npm install
```

## 📌 Environment Variables

Backend:

```env
MONGODB_URI=
JWT_SECRET_KEY=
STRIPE_SECRET_KEY=
CLOUDINARY_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_SECRET_KEY=
ADMIN_EMAIL=
ADMIN_PASSWORD=
FRONTEND_URL=
```

Frontend & Admin:

```env
VITE_BACKEND_URL=
```
